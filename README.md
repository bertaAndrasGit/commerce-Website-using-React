# About

A basic Ecommerce website based on [PedroTech's video](https://youtu.be/Wt3isV2irrA).

I built this project to grasp the fundamentals of React so I can apply them to my next project.

# Technologies

- React 19 
- React Hook Form
- React Router DOM

# Features

- Product Page
- Simple Authentication
- Shopping Cart
- Form Validation

# What I Learned

The basics of React (`useState`, `useEffect`, `useContext`) and custom routing for single-page websites.

# Running the Project

1. Clone repository.
2. Open PowerShell and run `npm install` to install the dependencies.
3. Run `npm run dev`.
4. Open the `localhost` link (if using Vite, just press `o` in the terminal).
